Настройки

Прогресс остаётся на этом устройстве. TestApp может полностью сохранить базу заданий для работы без сети и самостоятельно получать проверенные обновления из GitHub.

Тема оформления

Выбор сохраняется в браузере и применяется ко всему приложению.

Установить приложение

Скачай TestApp на устройство как PWA. После установки он появится среди приложений, откроется в отдельном окне и сможет работать автономно.

Установка зависит от возможностей браузераПереустанавливать TestApp при добавлении новых тестов не потребуется — база обновляется отдельно.

Автономная работа

Один раз сохрани всю текущую базу на устройство. После этого вопросы, ответы, статистика, ошибки и интервальные повторения доступны без подключения к интернету.

Проверяю режим хранения…Пользовательский прогресс и расписание повторений не отправляются на сервер.

Обновления тестов из GitHub

Ручная проверка теперь проходит полностью: приложение проверяет manifest, заново обращается ко всем опубликованным пакетам тестов, валидирует их и одновременно проверяет обновление самого TestApp.

Резервная копия прогресса

Экспортируй прогресс в файл, чтобы перенести его на другое устройство или сохранить перед очисткой браузера.

Импорт тестов

Административный импортёр читает XLSX локально, проверяет строки и формирует готовый JSON-пакет. Для каждого варианта ответа можно добавить собственное пояснение.

Приватность

GitHub раздаёт только общую версионированную базу тестов и обновления самого приложения. Ответы пользователей, ошибки, статистика и интервальное расписание остаются только в IndexedDB устройства.
