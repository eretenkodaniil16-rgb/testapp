# TestApp

Mobile-first PWA for solving, generating and reviewing educational test questions.

## Product goals

- unified question bank instead of isolated test files;
- hierarchy: subject → section → topic → subtopic;
- learning, exam, mistakes and weak-topic modes;
- persistent attempt history and per-question results;
- question revisions so historical results stay reproducible;
- XLSX/CSV import first, DOCX import later;
- installable PWA with an offline-capable path;
- PostgreSQL/Supabase backend with Auth and Storage.

## Planned stack

- Next.js App Router + TypeScript
- React
- PostgreSQL via Supabase
- Supabase Auth + Storage
- PWA
- GitHub Actions

Implementation is developed through feature branches and pull requests.
